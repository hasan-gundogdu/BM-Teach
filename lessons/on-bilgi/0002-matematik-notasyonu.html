Matematiksel Notasyon: Σ, Alt İndis, σ

Bu dersin sonunda: det(A) = Σσ sign(σ) · a1,σ(1) · a2,σ(2) ··· an,σ(n) formülündeki her sembolü okuyabilecek, formülü kendi kod bildiğin diline çevirebileceksin.

🎯 Neden bu? Ders 02'deki n-boyutlu determinant formülü, senin matematik geçmişinde olmayan bir sembol seti kullanıyordu (Σ, alt indis, σ). Bunlar aslında sana çok tanıdık kavramların (döngü, dizi, fonksiyon) farklı bir yazımı — 15+ yıllık yazılımcı olarak bunları zaten biliyorsun, sadece matematik gösterimini görmemişsin.

1. Σ (sigma) — toplama sembolü, aslında bir for döngüsü

Şunu gördüğünde:

Σi=1n ai

Matematikçi şunu demek istiyor: "i'yi 1'den n'e kadar say, her i için ai'yi topla." C# olarak:

double toplam = 0;
for (int i = 1; i <= n; i++)
{
    toplam += a[i];
}
return toplam;

Somut örnek: Σi=14 i² = 1² + 2² + 3² + 4² = 1+4+9+16 = 30.

2. Alt indis — bir dizinin/matrisin hangi elemanı

ai, "bir dizinin i'inci elemanı" demek — kodda a[i] ile aynı şey. İki alt indis varsa (ai,j), bu bir matrisin i'inci satır, j'inci sütunundaki eleman — kodda a[i][j]:

a2,3 = a[2][3] → matrisin 2. satır, 3. sütunundaki sayı

3. Fonksiyon notasyonu — σ(1) sadece bir metot çağrısı

Önce hatırlayalım: C#'ta bir fonksiyon (metot) girdi alır, çıktı döndürür:

int Kare(int x)
{
    return x * x;
}

Kare(3);  // → 9

Kare(3), "Kare fonksiyonuna 3'ü ver, sonucu al" demek. Matematikte de aynı fikir, sadece parantez kullanımı bizim de bildiğimiz gibi: f(3) = "f fonksiyonuna 3'ü ver".

Şimdi σ (sigma harfi — dikkat, büyük Σ ile karıştırma, o toplamaydı, bu küçük σ bambaşka bir şey, bir fonksiyon). σ(1) tam olarak Kare(3) gibi okunur: "σ fonksiyonuna 1'i ver, çıktısını al". Fonksiyonun ne işe yaradığını Bölüm 4'te göreceğiz.

4. Permütasyon — σ'nın gerçekte ne yaptığı

σ'nın yaptığı iş basit: 1, 2, ..., n sayılarını karıştırır (yeniden sıralar). Buna permütasyon denir. n=3 için bir örnek:

σ(1) = 2 σ(2) = 1 σ(3) = 3

Yani "1 numaraya sor, 2 cevabını ver; 2 numaraya sor, 1 cevabını ver; 3 numaraya sor, 3 cevabını ver." C#'ta bunu bir dizi olarak saklardın:

int[] sigma = { 2, 1, 3 };

Küçük ayrıntı (yazılımcı tuzağı): C# dizileri 0'dan başlar, matematik ise 1'den. Yani matematikteki σ(1), C# kodunda sigma[0]'a denk gelir (bir kaydırma var). Bunu bilmen yeterli, formülü okurken matematik tarafında kalacağız (1'den başlayan).

{1,2,3} için mümkün olan tüm karıştırma şekillerinin sayısı 3! = 6. Ders 02'de gördüğün Sarrus'un 6 terimi, işte bu 6 farklı karıştırmanın karşılığı — birazdan tam listesini göreceğiz (Bölüm 6).

5. sign(σ) — karıştırma "kaç adımda" yapıldı

sign(σ) şu soruyu soruyor: sıralı hâlden (1,2,3,...) bu karıştırmaya, kaç tane ikili takas (iki elemanın yerini değiştirme) ile ulaşılır — çift mi, tek mi?

  • Çift sayıda takas → sign(σ) = +1
  • Tek sayıda takas → sign(σ) = −1

Somut örnek: sigma = {2, 1, 3}. Sıralı hâl {1,2,3}'ten buna geçmek için tek bir takas yeterli: 1 ile 2'nin yerini değiştir. 1 takas = tek → sign(σ) = −1.

6. Şimdi tam formülü C# metodu gibi okuyalım

det(A) = Σσ sign(σ) · a1,σ(1) · a2,σ(2) ··· an,σ(n)

Bu formülün C# karşılığı — iç içe iki döngü, başka bir şey değil:

double Determinant(double[,] a, int n)
{
    double toplam = 0;

    foreach (var sigma in TumPermutasyonlar(n))   // Σ_σ → tüm permütasyonları gez
    {
        double carpim = 1;
        for (int i = 1; i <= n; i++)
        {
            carpim *= a[i, sigma[i]];             // a_(i,σ(i)) → satır i, sütun σ(i)
        }
        toplam += Sign(sigma) * carpim;           // sign(σ) ile işaretleyip topla
    }

    return toplam;
}

Dış döngü (foreach sigma): mümkün olan her karıştırmayı tek tek dener. İç döngü (for i): o karıştırmaya göre her satırdan doğru sütunu seçip çarpar. TumPermutasyonlar ve Sign'ı burada "hazır fonksiyon" gibi düşün — nasıl çalıştıklarını Bölüm 4-5'te zaten gördün.

7. n=3 için tüm 6 permütasyonu görelim (Sarrus ile bağlantı)

Ders 02'de gördüğün Sarrus'un 6 terimi, işte bu 6 permütasyonun karşılığı:

σ (dizi)Takas sayısısign(σ)Terim
[1,2,3]0 (çift)+1+a₁₁a₂₂a₃₃
[2,3,1]2 (çift)+1+a₁₂a₂₃a₃₁
[3,1,2]2 (çift)+1+a₁₃a₂₁a₃₂
[3,2,1]1 (tek)−1−a₁₃a₂₂a₃₁
[1,3,2]1 (tek)−1−a₁₁a₂₃a₃₂
[2,1,3]1 (tek)−1−a₁₂a₂₁a₃₃

Bu 6 satırı topla — Ders 02'deki aei+bfg+cdh−ceg−bdi−afh formülünün ta kendisi çıkıyor (harfler yerine ai,j notasyonu kullanılmış hâli).

8. Şimdi sen dene

Soru 1. Σi=13 2i kaçtır?

Cevabı göster

2·1 + 2·2 + 2·3 = 2+4+6 = 12.

Soru 2. a3,2 bir matriste neyi ifade eder?

Cevabı göster

3. satır, 2. sütundaki eleman.

Soru 3. σ = [3,1,2] ise σ(2) kaçtır?

Cevabı göster

σ(2) = 1 (dizinin 2. konumundaki değer).

Soru 4 (kavram). n=4 için kaç farklı permütasyon (dolayısıyla determinant formülünde kaç terim) olur?

Cevabı göster

4! = 24 permütasyon/terim.
