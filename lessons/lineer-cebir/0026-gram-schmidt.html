Gram-Schmidt Yöntemi

Bu dersin sonunda: elindeki herhangi bir bazı önce ortogonal, sonra ortonormal bir baza dönüştürebileceksin.

🎯 Neden bu? Ders 25 ortonormal bazın ne kadar işe yaradığını gösterdi — ama elimizdeki baz genelde ortonormal değil. Gram-Schmidt, herhangi bir bazı ortonormal bir baza çeviren mekanik yöntemdir. Ders 29'da simetrik bir matrisin tekrarlı özdeğerinin eigen uzayı için tam olarak bu gerekecek.

1. Yöntem (PDF 7.3.3)

Sonlu boyutlu içsel çarpım uzayı V'nin her bir sıfırdan farklı W altuzayının ortogonal ve ortonormal bazları mevcuttur. Eğer {a₁, a₂, ..., aₙ}, W'nin bir bazı ise, {b₁, b₂, ..., bₙ} gibi bir ortogonal baz ve {c₁, c₂, ..., cₙ} gibi bir ortonormal baz bulmak için uygulanan Gram-Schmidt Yöntemi:

b₁ = a₁
b₂ = a₂ − ( ⟨a₂, b₁⟩ / ⟨b₁, b₁⟩ ) b₁
b₃ = a₃ − ( ⟨a₃, b₁⟩ / ⟨b₁, b₁⟩ ) b₁ − ( ⟨a₃, b₂⟩ / ⟨b₂, b₂⟩ ) b₂
⋮
bₙ = aₙ − ( ⟨aₙ, b₁⟩ / ⟨b₁, b₁⟩ ) b₁ − ( ⟨aₙ, b₂⟩ / ⟨b₂, b₂⟩ ) b₂ − ... − ( ⟨aₙ, bₙ₋₁⟩ / ⟨bₙ₋₁, bₙ₋₁⟩ ) bₙ₋₁

Not (PDF'deki dizgi hatası). Slaytta b₂ satırı "b₂ = a₃ − ..." olarak basılmış; doğrusu b₂ = a₂ − ...'dir (Örnek 16'da hocanın kendisi de a₂ kullanıyor).

Sembollerin karşılığı. aᵢ: elimizdeki (ortogonal olmayan) baz vektörleri. bᵢ: üretilen ortogonal baz vektörleri. ⟨x, y⟩: iç (nokta) çarpım. ⟨bᵢ, bᵢ⟩: bᵢ'nin kendisiyle çarpımı, yani ‖bᵢ‖². Şart: {aᵢ} zaten lineer bağımsız olmalı (baz olmalı) — aksi hâlde bir adımda bᵢ = 0 çıkar.

Ortonormal baza geçiş: her bᵢ'yi kendi uzunluğuna böl —

cᵢ = bᵢ / ‖bᵢ‖
Sezgi / ek açıklama — formül aslında ne yapıyor? (⟨a₂,b₁⟩ / ⟨b₁,b₁⟩) b₁ ifadesi, a₂'nin b₁ doğrultusundaki gölgesidir (izdüşüm). Formül bu gölgeyi a₂'den çıkarıyor; geriye kalan parça artık b₁'e diktir. Üçüncü adımda hem b₁ hem b₂ yönündeki gölgeler çıkarılır. Yani yöntem tek cümlede: "önceki yönlerin payını at, kalan dik olur."

2. Örnek 16 (PDF 7.3.3.1)

{a₁, a₂}, altuzay W'nun bir bazı olsun. Burada a₁ = [1  1  0] ve a₂ = [2  −1  3] baz vektörlerini ortogonal baz haline dönüştürünüz. Daha sonra ortogonal baz vektörlerini normalize ederek ortonormal baz elde ediniz. Bu işlemleri gerçekleştirmek için Gram-Schmidt yöntemini kullanınız.

1. Adım

b₁ = a₁ = [1  1  0]

2. Adım

b₂ = a₂ − ( ⟨a₂, b₁⟩ / ⟨b₁, b₁⟩ ) b₁

Payı hesapla: ⟨a₂, b₁⟩ = ⟨[2 −1 3], [1 1 0]⟩ = 2(1) + (−1)(1) + 3(0) = 2 − 1 + 0 = 1

Paydayı hesapla: ⟨b₁, b₁⟩ = ⟨[1 1 0], [1 1 0]⟩ = 1(1) + 1(1) + 0(0) = 2

b₂ = [2  −1  3] − (1/2)·[1  1  0]

Skalerle çarpım: (1/2)[1 1 0] = [1/2  1/2  0]

Çıkarma (bileşen bileşen): [2 − 1/2,   −1 − 1/2,   3 − 0]

b₂ = [ 3/2   −3/2   3 ]

b₂'ye [3/2  −3/2  3], veya (3/2)[1  −1  2], veya [1  −1  2] olarak seçilebilir.

(Ortogonal bazda yön önemlidir, ölçek değil — sıfırdan farklı bir katıyla değiştirmek diklikleri bozmaz. Kesirlerden kurtulmak için [1 −1 2] seçmek hesabı sadeleştirir.)

Dolayısıyla {b₁, b₂}, yani { [1  1  0],  [1  −1  2] }:

⟨b₁, b₂⟩ = 1(1) + 1(−1) + 0(2) = 0

olduğundan W altuzayının bir ortogonal bazıdır.

3. Adım — normalize et

c₁ = b₁ / ‖b₁‖ = [1  1  0] / ‖[1  1  0]‖

‖[1 1 0]‖ = √(1² + 1² + 0²) = √2

c₁ = [ 1/√2   1/√2   0 ]
c₂ = b₂ / ‖b₂‖ = [1  −1  2] / ‖[1  −1  2]‖

‖[1 −1 2]‖ = √( 1² + (−1)² + 2² ) = √(1 + 1 + 4) = √6

c₂ = [ 1/√6   −1/√6   2/√6 ]

Kontrol

⟨c₁, c₂⟩ = (1/√2)(1/√6) + (1/√2)(−1/√6) + 0(2/√6)

= 1/√12 − 1/√12 + 0 = 0 ✓

Uzunluklar: ‖c₁‖ = √(½ + ½ + 0) = 1 ✓   ‖c₂‖ = √(1/6 + 1/6 + 4/6) = √1 = 1 ✓

Olduğundan {c₁, c₂}, W altuzayının ortonormal bir bazıdır.

3. Sık yapılan hatalar

  • Payda karışıklığı: ⟨b₁, b₁⟩ yerine ⟨a₁, a₁⟩ ya da ‖b₁‖ (karesiz) yazmak. Payda her zaman bᵢ'nin kendisiyle iç çarpımıdır, yani ‖bᵢ‖².
  • İzdüşümü aᵢ'den değil bᵢ₋₁'den çıkarmak. Her adımda çıkarma işlemi orijinal aᵢ üzerinde yapılır.
  • 3. ve sonraki adımlarda önceki tüm b'lerin izdüşümünü çıkarmayı unutmak (yalnızca bir öncekini çıkarmak).
  • Ölçek sadeleştirmesini yaptıktan sonra normalize adımında eski vektörün normunu kullanmak. [1 −1 2] seçtiysen normu √6'dır, [3/2 −3/2 3]'ün normu değil (o 3√6/2).
  • Bağımlı bir kümeye Gram-Schmidt uygulamak. Bir adımda bᵢ = 0 çıkarsa, girdi baz değildi demektir.

4. Şimdi sen dene

Soru 1 (kavram). Gram-Schmidt'te a₁ ile a₂'nin sırasını değiştirirsen sonuç değişir mi? Elde edilen küme yine ortonormal olur mu?

Cevabı göster

Vektörler değişir, ortonormallik değişmez. b₁ her zaman ilk vektörün kendisidir; sırayı değiştirirsen farklı bir ortonormal baz elde edersin. Aynı altuzayın birden çok ortonormal bazı vardır — hepsi geçerlidir. Sınavda cevabın "kitabınkinden farklı ama ortonormal ve aynı uzayı kapsıyorsa" doğrudur; farklı sıralama seçtiğini belirtmek iyi olur.

Soru 2 (temel işlem). a₁ = [1  0  1], a₂ = [1  1  0] için Gram-Schmidt uygulayarak ortonormal bir baz bul.

Cevabı göster

b₁ = [1  0  1]

⟨a₂, b₁⟩ = 1(1) + 1(0) + 0(1) = 1;   ⟨b₁, b₁⟩ = 1 + 0 + 1 = 2

b₂ = [1  1  0] − (1/2)[1  0  1] = [1 − 1/2,  1 − 0,  0 − 1/2] = [1/2  1  −1/2]

Sadeleştir (2 ile çarp): b₂ = [1  2  −1]. Kontrol: ⟨b₁, b₂⟩ = 1 + 0 − 1 = 0 ✓

‖b₁‖ = √2 → c₁ = [1/√2  0  1/√2]

‖b₂‖ = √(1 + 4 + 1) = √6 → c₂ = [1/√6  2/√6  −1/√6]

Kontrol: ⟨c₁,c₂⟩ = 1/√12 + 0 − 1/√12 = 0 ✓; ‖c₂‖² = 1/6 + 4/6 + 1/6 = 1 ✓

Soru 3 (sınav seviyesi). a₁ = [1  1  1], a₂ = [0  1  1], a₃ = [0  0  1] bazına Gram-Schmidt uygulayıp üç ortonormal vektör elde et. (Üçüncü adımda iki izdüşümün de çıkarılması gerekiyor.)

Cevabı göster

b₁ = [1  1  1],   ⟨b₁,b₁⟩ = 3

b₂: ⟨a₂, b₁⟩ = 0 + 1 + 1 = 2 → b₂ = [0 1 1] − (2/3)[1 1 1] = [−2/3,  1/3,  1/3]

Sadeleştir (3 ile çarp): b₂ = [−2  1  1]. Kontrol: ⟨b₁,b₂⟩ = −2 + 1 + 1 = 0 ✓. ⟨b₂,b₂⟩ = 4 + 1 + 1 = 6

b₃: ⟨a₃, b₁⟩ = 0 + 0 + 1 = 1;   ⟨a₃, b₂⟩ = 0 + 0 + 1 = 1

b₃ = [0 0 1] − (1/3)[1 1 1] − (1/6)[−2 1 1]

(1/3)[1 1 1] = [1/3, 1/3, 1/3];   (1/6)[−2 1 1] = [−1/3, 1/6, 1/6]

b₃ = [0 − 1/3 + 1/3,   0 − 1/3 − 1/6,   1 − 1/3 − 1/6] = [0,  −1/2,  1/2]

Sadeleştir (2 ile çarp): b₃ = [0  −1  1]. Kontrol: ⟨b₁,b₃⟩ = 0 − 1 + 1 = 0 ✓, ⟨b₂,b₃⟩ = 0 − 1 + 1 = 0 ✓

Normalize: c₁ = [1 1 1]/√3,   c₂ = [−2 1 1]/√6,   c₃ = [0 −1 1]/√2

Son kontrol: ‖c₂‖² = (4+1+1)/6 = 1 ✓, ‖c₃‖² = (0+1+1)/2 = 1 ✓
