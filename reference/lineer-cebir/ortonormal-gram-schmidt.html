Ortonormal Baz & Gram-Schmidt — Hızlı Başvuru

Lineer Cebir BM213 · Ders 25-27 (Bölüm 7.3.2-7.4) özeti.

Tanımlar

Ortogonal (iki vektör): ⟨a, b⟩ = 0
Ortogonal küme: her çift ortogonal
Ortonormal küme: ortogonal + her vektörün uzunluğu 1
Ortogonal/ortonormal baz: hem baz hem ortogonal/ortonormal olan küme
⟨a, b⟩ = a₁b₁ + a₂b₂ + ... + aₙbₙ  ·  ‖a‖ = √(a₁² + ... + aₙ²)
Normalize: c = a / ‖a‖ — doğrultuyu değiştirmez, ortogonalliği bozmaz.

Kontrol sırası (2 adım, ikisi de şart)

  1. Bütün çiftlerin iç çarpımı 0 mı?  (n vektör için n(n−1)/2 çift)
  2. Bütün normlar 1 mi?
Yalnızca 1 sağlanıyorsa ortogonal; ikisi birden sağlanıyorsa ortonormal.

Gram-Schmidt yöntemi

b₁ = a₁
b₂ = a₂ − ( ⟨a₂,b₁⟩ / ⟨b₁,b₁⟩ ) b₁
b₃ = a₃ − ( ⟨a₃,b₁⟩ / ⟨b₁,b₁⟩ ) b₁ − ( ⟨a₃,b₂⟩ / ⟨b₂,b₂⟩ ) b₂
⋮
ortonormal:   cᵢ = bᵢ / ‖bᵢ‖
Ne yapıyor: her adımda aᵢ'den, önceki tüm b yönlerindeki izdüşümü (gölgeyi) çıkarıyor; kalan parça dik olur.
Payda: ⟨bᵢ, bᵢ⟩ = ‖bᵢ‖² — karekök yok. bᵢ zaten birim vektörse payda 1'dir.
Şart: girdi kümesi lineer bağımsız olmalı; değilse bir adımda bᵢ = 0 çıkar.
Ara sonucu sadeleştirmek serbest ([3/2, −3/2, 3] → [1, −1, 2]); normu kullandığın biçime göre hesapla.

Ortogonal matris

Tanım: sütunları ortonormal küme oluşturan matris.
Test: AᵀA = I  ⟺  A⁻¹ = Aᵀ
det(A) = ±1 olmak zorundadır.
Simetrik matris (A = Aᵀ) ile ortogonal matris (AᵀA = I) farklı kavramlardır; bir matris ikisi birden olabilir (ör. I).

Nerede kullanılır

Simetrik bir matrisi ortogonal olarak köşegenleştirirken (D = PᵀAP):
• Farklı özdeğerlerin özvektörleri zaten dik → yalnızca normalize et.
• Aynı özdeğerin eigen uzayında 2+ vektör varsa dik olmayabilir → o uzayın içinde Gram-Schmidt çalıştır.
Gram-Schmidt farklı eigen uzayları arasında uygulanmaz — gereksizdir.

Sık hatalar

• İç çarpımları kontrol edip normları atlayarak "ortonormal" demek.
• Ortogonallikte bir çifti (ör. b₁·b₃) atlamak.
• Gram-Schmidt paydasında ‖bᵢ‖ (karesiz) kullanmak.
• İzdüşümü aᵢ yerine bᵢ₋₁'den çıkarmak.
• 3. adımda yalnızca bir önceki b'nin izdüşümünü çıkarmak.
• Sadeleştirilmiş vektörle eski normu birlikte kullanmak.
• Ortogonallik testinde AᵀA yerine A·A hesaplamak.
