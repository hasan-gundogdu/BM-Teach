Kaynak dönüşümü

V_s = I_s · R ⟺ I_s = V_s / R
R değeri değişmez. Gerilim kaynağı+seri R ⟺ Akım kaynağı+paralel R. Akım kaynağının oku, gerilim kaynağının + ucuna doğru bakar.
Örnek: 12V + 4Ω seri → I_s = 12/4 = 3A, 4Ω paralel.
Ters: 2A + 6Ω paralel → V_s = 2×6 = 12V, 6Ω seri.
