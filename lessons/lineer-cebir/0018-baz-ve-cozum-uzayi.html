Lineer Cebir · Ders 18 · Bölüm 7.1.2

Baz (Basis) ve Çözüm Uzayı

Bu dersin sonunda: bir homojen sistemin çözüm uzayı için bir baz bulabilecek ve "baz" kelimesinin tam olarak neyi garanti ettiğini bileceksin.

🎯 Neden bu? Bir sonraki derste özvektör bulacağız — ve özvektör bulmak, tam olarak (λI − A)x = 0 homojen sisteminin çözüm uzayına bir baz bulmak demek. Yani bu ders, özvektör dersinin dilbilgisi. Ayrıca "kaç tane bağımsız özvektör var?" sorusu (diyagonalizasyonun kader sorusu) doğrudan bu bazın boyutu.

1. Sezgi: düzlemde iki yön yeter

Düzlemde, doğrultuları farklı iki vektör a ve b alalım. Düzlemin herhangi bir c ≠ 0 vektörü için

c = x·a + y·b

eşitliğini sağlayan, en az biri sıfırdan farklı x ve y sayıları her zaman bulunabilir. Sebep geometrik: a ve b üzerine, köşegeni c olan bir paralelkenar kurulabilir.

Diğer bir deyişle: düzlemde paralel olmayan iki vektör bir baz (basis) teşkil eder ve düzlemin bütün vektörleri bu baz vektörlerinin lineer kombinezonu olarak ifade edilebilir.

Uzayda aynı düzleme paralel olmayan üç vektör a, b, c alalım. Bu üç vektör de bir baz teşkil eder: uzayın herhangi bir d vektörü

d = x·a + y·b + z·c

şeklinde yazılabilir — çünkü bu üç vektör üzerine, köşegeni d olan bir paralelyüzlü kurulabilir (PDF Şekil 7.2). Buradan doğrudan çıkan bir sonuç: uzayda dört vektör her zaman lineer bağımlıdır (üçü zaten uzayın tamamını üretiyorsa, dördüncüsü onların kombinezonudur).

2. Tanım ve teorem (PDF, Bölüm 7.1.2)

Tanım. V herhangi bir vektör uzayı ve S = {v₁, v₂, ..., vₙ} bu uzaydaki vektörlerin bir kümesi olsun. Aşağıdaki iki şart birlikte sağlanırsa S, V uzayı için bir bazdır (basis):

a) S lineer bağımsızdır (Ders 11);
b) S, V'yi kapsar (spans) — yani V'nin her elemanı S'deki vektörlerin lineer kombinezonudur.

Teorem. Eğer S = {v₁, v₂, ..., vₙ}, V vektör uzayı için bir baz ise, V'deki her v vektörü

v = c₁v₁ + c₂v₂ + ... + cₙvₙ

şeklinde sadece bir şekilde ifade edilebilir.

Sezgi / ek açıklama — iki şart neden ikisi birden gerekli?
"Kapsar" tek başına yetseydi, gereğinden fazla vektör de baz sayılırdı (ör. düzlemde üç vektör) — o zaman aynı v'yi birçok farklı katsayı üçlüsüyle yazabilirdin, teklik bozulurdu. "Bağımsız" tek başına yetseydi, gereğinden az vektör de baz sayılırdı (ör. düzlemde tek vektör) — o zaman bazı vektörler hiç ifade edilemezdi. Baz = tam yeterli sayıda vektör: ne fazla, ne eksik. Teoremdeki "sadece bir şekilde" ifadesi bu dengenin sonucudur.

Adım 3 — bağımlı / bağımsız değişkenleri oku

PDF'nin okuma kuralı, satır satır:

• 1. satır: sıfırdan farklı ilk değer 1, bulunduğu sütun (1. sütun) içindeki diğer elemanlar sıfır → x₁ bağımlı değişkendir.

• 2. satır: sıfırdan farklı ilk değer 1, sütunu 3. sütun, o sütundaki diğer elemanlar sıfır → x₃ bağımlı.

• 3. satır: sıfırdan farklı ilk değer 1, sütunu 4. sütun → x₄ bağımlı.

• 4. satır: tüm elemanları sıfır — bilgi taşımıyor.

Geriye kalan x₂ ve x₅ bağımsız (serbest) değişkenlerdir. Rank r = 3, bilinmeyen sayısı n = 5 → serbest değişken sayısı n − r = 2 (Ders 13).

Adım 4 — denklemleri yaz ve çöz

x₁ + x₂        + x₅ = 0  ·  x₃ + x₅ = 0  ·  x₄ = 0

Bağımlıları serbestler cinsinden çöz:

x₁ = −x₂ − x₅,   x₃ = −x₅,   x₄ = 0

Serbestlere parametre ata: x₂ = s, x₅ = t. Böylece:

x₁ = −s − t,   x₂ = s,   x₃ = −t,   x₄ = 0,   x₅ = t

Bu her zaman böyledir: serbest değişken yöntemiyle üretilen vektörler, her biri "kendi" serbest değişkeninde 1, diğerlerinde 0 taşıdığı için otomatik olarak bağımsız çıkar. (Sezgi / ek açıklama.)

Doğrulama — v₁ ve v₂ gerçekten çözüm mü?

v₁ = (−1, 1, 0, 0, 0):

1. denklem: 2(−1) + 2(1) − 0 + 0 = 0 ✓   2. denklem: −(−1) − 1 + 0 − 0 + 0 = 0 ✓

3. denklem: (−1) + 1 − 0 − 0 = 0 ✓   4. denklem: 0 + 0 + 0 = 0 ✓

v₂ = (−1, 0, −1, 0, 1):

1. denklem: 2(−1) + 0 − (−1) + 1 = −2 + 1 + 1 = 0 ✓

2. denklem: −(−1) − 0 + 2(−1) − 0 + 1 = 1 − 2 + 1 = 0 ✓

3. denklem: (−1) + 0 − 2(−1) − 1 = −1 + 2 − 1 = 0 ✓

4. denklem: (−1) + 0 + 1 = 0 ✓

4. Sık yapılan hatalar

  • Serbest değişkeni yanlış seçmek. Serbest olanlar, kanonik şekilde pivot içermeyen sütunlara ait değişkenlerdir. Burada 2. ve 5. sütunlarda pivot yok → x₂ ve x₅ serbest. "En sondaki değişkenleri serbest seç" diye bir kural yoktur.
  • Sıfır satırını "bir denklem" sayıp rank'ı fazla hesaplamak.
  • Çözümü tek bir vektör olarak bırakıp s ve t'ye ayırmamak — o zaman baz görünmez, yalnızca genel çözüm görünür. Soru "baz" istiyorsa parametrelere ayırma şart.
  • Baz vektörlerini bulup bağımsızlığı hiç kontrol etmemek. (Bu yöntemle otomatik sağlanır ama gerekçesi yazılmalı.)

5. Şimdi sen dene

Soru 1 (kavram). Bir çözüm uzayının bazı 3 vektör içeriyor. Aynı çözüm uzayı için 4 vektörlü bir baz bulmak mümkün müdür? Neden?

Cevabı göster

Hayır. Bir vektör uzayının bütün bazları aynı sayıda vektör içerir; bu sayı uzayın boyutudur. 4 vektör alsaydın kapsama şartı yine sağlanırdı ama bağımsızlık bozulurdu (dördüncüsü diğer üçünün kombinezonu olmak zorunda) — dolayısıyla baz olmaz. Baz tanımının iki şartından biri düşer.

Soru 2 (temel işlem). x₁ + 2x₂ − x₃ = 0 tek denklemli homojen sistemin çözüm uzayı için bir baz bul ve boyutunu söyle.

Cevabı göster

Kanonik şekil zaten hazır: [1  2  −1 | 0], rank r = 1, n = 3 → serbest değişken sayısı n − r = 2.

Pivot 1. sütunda → x₁ bağımlı; x₂ = s, x₃ = t serbest.

x₁ = −2x₂ + x₃ = −2s + t

(x₁,x₂,x₃) = (−2s+t, s, t) = s(−2, 1, 0) + t(1, 0, 1)

Baz: {(−2,1,0), (1,0,1)}, boyut 2. Kontrol: −2+2·1−0 = 0 ✓, 1+0−1 = 0 ✓
